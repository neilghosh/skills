# Public YouTube Multilingual TTS (`edge-tts` + `IndicF5-MLX`)

This directory holds only YouTube-safe, copyright-clear multilingual synthesis resources for public documentary uploads:
- `uk_english`: `en-GB-RyanNeural` (Edge-TTS Neural)
- `us_english`: `en-US-AndrewMultilingualNeural` (Edge-TTS Neural)
- `hindi`: `hi-IN-MadhurNeural` (Edge-TTS Neural)
- `bangla`: `bn-IN-BashkarNeural` (Edge-TTS Neural)
- `odia`: `odia_native_clean.wav` (IIT Madras / AI4Bharat `IndicTTS_Odia` open-source studio reference for `IndicF5-MLX`)
- `indic_f5_mlx/vocab.txt`: 2,545-token Indic script vocabulary

> **Note:** Personal and sports commentary voices (`neil`, `nasser`, `atherton`, `shastri`, `tony`, `holding`, `attenborough`, `bear_hindi`) live in the separate [`youtube-custom-voice-player`](../../youtube-custom-voice-player) skill for private/custom HTML5 player overdubbing.
